# Private font assets

This directory is intentionally excluded from Git except for this README.

IRANSansX and Yekan Bakh are treated as private/proprietary assets. Install licensed copies locally or through the application installer; do not commit their binaries to the public repository.

Expected runtime paths:

- `iransansx/IRANSansXFaNum-Light.woff2`
- `iransansx/IRANSansXFaNum-Regular.woff2`
- `iransansx/IRANSansXFaNum-Medium.woff2`
- `iransansx/IRANSansXFaNum-DemiBold.woff2`
- `iransansx/IRANSansXFaNum-Bold.woff2`
- `iransansx/IRANSansXFaNum-ExtraBold.woff2`
- `iransansx/IRANSansXFaNum-Black.woff2`
- `yekan-bakh/YekanBakhFaNum-Light.woff2`
- `yekan-bakh/YekanBakhFaNum-Regular.woff2`
- `yekan-bakh/YekanBakhFaNum-SemiBold.woff2`
- `yekan-bakh/YekanBakhFaNum-Bold.woff2`
- `yekan-bakh/YekanBakhFaNum-ExtraBold.woff2`
- `yekan-bakh/YekanBakhFaNum-Black.woff2`

The helper at `scripts/fonts/install-private-fonts.php` extracts these files from the licensed ZIP packages without publishing them to Git.
