# SEO OS 0.1.0-alpha.2

اصلاح نصب روی هاست‌های اشتراکی (cPanel / CloudLinux با LiteSpeed یا Apache). امکانات همان نسخه 0.1.0-alpha.1 است.

## اصلاح‌ها

- **خطای ۴۰۴ برای همه آدرس‌ها جز صفحه اول** (مثلاً `/install`): فایل `public/.htaccess` در بسته نبود. حالا همراه بسته است (به همراه `favicon.svg` و `apple-touch-icon.png`).
- **شکست مرحله migration در نصب‌کننده:** هاست‌هایی که `innodb_default_row_format=compact` دارند کلید یکتای ایمیل را رد می‌کردند (خطای 1709، سقف ۷۶۷ بایت). جدول‌ها حالا صریحاً با `ROW_FORMAT=DYNAMIC` ساخته می‌شوند؛ روی MariaDB 10.6، MariaDB 10.11 و MySQL 8.0 همه migrationها از صفر آزموده شد.
- **تلاش مجدد واقعاً امن است:** اگر یک migration نیمه‌کاره شکست بخورد، جدول‌هایی که همان تلاش ساخته بود حذف می‌شوند تا تلاش بعدی با «جدول از قبل وجود دارد» گیر نکند. جدول‌هایی که از قبل در پایگاه داده بودند دست نمی‌خورند.
- **دلیل شکست نمایش داده می‌شود:** نام migration، نوع خطا و کد SQLSTATE/کد پایگاه داده (بدون رمز، آدرس سرور، مسیر فایل یا متن SQL) و جزئیات کامل در `storage/logs` ثبت می‌شود.
- **migrationها در دسته‌های محدود اجرا می‌شوند** تا یک درخواست به سقف زمان اجرای PHP هاست نرسد؛ اگر چیزی باقی ماند، همان دکمه را دوباره بزنید.
- **PHP 8.3 پشتیبانی می‌شود** (قبلاً 8.4.1). اگر نسخه PHP قدیمی‌تر باشد، صفحه‌ای روشن «PHP 8.3+ لازم است (نسخه فعلی: …)» نمایش داده می‌شود، نه پیام گمراه‌کننده «بازیابی به‌روزرسانی لازم است».

## اگر نصب 0.1.0-alpha.1 نیمه‌کاره مانده است

نصب قبلی جدول‌های `migrations` و `users` را در پایگاه داده جا گذاشته است. پیش از نصب این نسخه، از phpMyAdmin همه جدول‌های همان پایگاه داده را حذف کنید (یا یک پایگاه داده خالی تازه بسازید). سپس پوشه قبلی را با محتوای این بسته جایگزین کنید؛ فایل `.env` و پوشه `storage` نصب قبلی را نگه دارید یا نصب را از اول شروع کنید.

## نیازمندی‌های هاست

- PHP **8.3** یا بالاتر با افزونه‌های: `ctype`, `fileinfo`, `filter`, `hash`, `mbstring`, `openssl`, `pcre`, `pdo`, `pdo_mysql`, `session`, `tokenizer`, `xml`. اگر PHP خط فرمان (cron) نسخه دیگری است، آن هم باید 8.3+ باشد.
- پایگاه داده **MariaDB 10.6+** یا **MySQL 8+** (آزمون‌های کامل روی MariaDB 10.11 اجرا می‌شوند)، با یک پایگاه داده خالی و یک کاربر برای آن.
- امکان تنظیم cron (دو خط، که نصب‌کننده دقیقاً نشانتان می‌دهد).
- برای بارگذاری بسته‌های به‌روزرسانی و فایل پشتیبان، سقف آپلود PHP دست‌کم **256 مگابایت** پیشنهاد می‌شود.
- روی هاست به Node.js، npm یا Composer نیازی نیست.

## نصب

1. فایل `seo-os-0.1.0-alpha.2.zip` یا `.tar.gz` را از همین صفحه دانلود کنید و SHA-256 آن را با `SHA256SUMS` مقایسه کنید.
2. آن را روی هاست باز کنید. ریشه وب (document root) دامنه را روی پوشه **`public`** همین نسخه بگذارید. فایل `public/.htaccess` باید کنار `index.php` باشد (در مدیر فایل cPanel گزینه نمایش فایل‌های مخفی را روشن کنید).
3. پوشه‌های `storage` و `bootstrap/cache` باید برای PHP قابل نوشتن باشند.
4. آدرس سایت را در مرورگر باز کنید و به `/install` بروید.
5. دو خط cron که نصب‌کننده نشان می‌دهد را در هاست اضافه کنید.

## نکته‌های مهم

- SHA-256 فقط سالم رسیدن فایل را ثابت می‌کند، نه هویت سازنده را؛ این نسخه امضای دیجیتال ندارد. فقط از همین صفحه رسمی دانلود کنید.

---

**English summary.** Shared-host install fixes: ships `public/.htaccess` (and icons), so routes other than `/` no longer 404 on Apache/LiteSpeed; creates tables with `ROW_FORMAT=DYNAMIC`, so migrations work on hosts with `innodb_default_row_format=compact` (error 1709, 767-byte key limit), verified from scratch on MariaDB 10.6, MariaDB 10.11 and MySQL 8.0; a failed migration removes the tables it created, so retrying is safe; the installer shows a sanitized failure reason (migration, exception class, SQLSTATE/driver code) and logs the full error; migrations run in time-bounded batches; PHP 8.3 is now supported, with a clear page on older PHP. If a 0.1.0-alpha.1 install stopped at migrations, drop the leftover tables (or use a fresh empty database) before installing this release.
