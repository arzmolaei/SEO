# SEO OS 0.1.0-alpha.1

اولین نسخه قابل نصب SEO OS: یک فضای کاری شخصی برای انجام سئوی سایت خودتان، فارسی و راست‌به‌چپ، که روی هاست خودتان اجرا می‌شود و به هیچ سرویس خارجی (گوگل، هوش مصنوعی، CDN) نیاز ندارد.

این نسخه «آلفا» است: برای استفاده واقعی خودتان آماده است، اما پیش از به‌روزرسانی‌ها همیشه پشتیبان بگیرید.

## در این نسخه

- **مسیر راهنما و «الان چه کار کنم؟»** در نمای کلی پروژه، با وضعیت واقعی هر مرحله.
- **کلمات کلیدی:** ورود CSV یا متن، تشخیص نیت، خوشه‌بندی، اختصاص خوشه به صفحه، صف بررسی و خروجی CSV برنامه سئو.
- **صفحه‌ها:** عنوان، توضیحات متا و H1 هر صفحه با چک‌لیست ساده و راهنمای رفع هر مورد.
- **بررسی صفحه‌های سایت خودتان:** وضعیت هر صفحه در سایت (کد پاسخ، noindex، canonical، عنوان، توضیحات، H1، تعداد کلمات).
- **محتوا:** بریف از روی خوشه و تقویم محتوا (پیش‌نویس، بازبینی، منتشرشده).
- **کارها:** فهرست کارهای شخصی، وصل به صفحه یا خوشه، با موعد.
- **لینک‌سازی داخلی:** پیشنهاد اینکه کدام صفحه به کدام لینک بدهد، با متن لینک.
- **عملکرد:** ورود CSV سرچ کنسول (پرسش‌ها و صفحه‌ها) و فهرست فرصت‌ها.
- **گزارش پروژه:** خلاصه قابل چاپ و CSV برای هر دوره.
- **نصب از مرورگر، پشتیبان‌گیری و بازیابی کامل، و به‌روزرسانی با بازگردانی خودکار.**

## نیازمندی‌های هاست

- PHP **8.4.1** یا بالاتر با افزونه‌های: `ctype`, `fileinfo`, `filter`, `hash`, `mbstring`, `openssl`, `pcre`, `pdo`, `pdo_mysql`, `session`, `tokenizer`, `xml`.
- پایگاه داده **MariaDB 10.11+** (پیشنهادی) یا **MySQL 8+**، با یک پایگاه داده خالی و یک کاربر برای آن.
- امکان تنظیم cron (دو خط، که نصب‌کننده دقیقاً نشانتان می‌دهد).
- برای بارگذاری بسته‌های به‌روزرسانی و فایل پشتیبان، سقف آپلود PHP دست‌کم **256 مگابایت** پیشنهاد می‌شود.
- روی هاست به Node.js، npm یا Composer نیازی نیست.

## نصب

1. فایل `seo-os-0.1.0-alpha.1.zip` یا `.tar.gz` را از همین صفحه دانلود کنید و SHA-256 آن را با `SHA256SUMS` مقایسه کنید.
2. آن را روی هاست باز کنید. ریشه وب (document root) دامنه را روی پوشه **`public`** همین نسخه بگذارید.
3. پوشه‌های `storage` و `bootstrap/cache` باید برای PHP قابل نوشتن باشند.
4. آدرس سایت را در مرورگر باز کنید و به `/install` بروید. نصب‌کننده فارسی مرحله‌به‌مرحله هاست را بررسی می‌کند، اطلاعات پایگاه داده را می‌گیرد، جدول‌ها را می‌سازد و حساب مالک را ایجاد می‌کند.
5. دو خط cron که نصب‌کننده نشان می‌دهد (زمان‌بند و صف کارها) را در هاست اضافه کنید.

## شروع کار

1. یک پروژه بسازید و کلمات کلیدی‌تان را وارد کنید.
2. از «نمای کلی» پروژه، بخش «الان چه کار کنم؟» را دنبال کنید: بررسی نیت، ساخت خوشه، اختصاص صفحه، آماده کردن و خروجی گرفتن.
3. سپس صفحه‌ها، محتوا، کارها، لینک‌ها، داده سرچ کنسول و گزارش را به کار بگیرید.

## پشتیبان‌گیری و به‌روزرسانی

- پشتیبان کامل و بازیابی: `تنظیمات` → `پشتیبان‌گیری و بازیابی`.
- به‌روزرسانی: `تنظیمات` → `به‌روزرسانی و بازیابی نسخه`، با بسته `.seoupdate`. پیش از هر به‌روزرسانی یک پشتیبان جداگانه بگیرید.
- جزئیات: `docs/backup-restore-operations.md` و `docs/update-recovery-operations.md` در مخزن.

## نکته‌های مهم

- SHA-256 فقط سالم رسیدن فایل را ثابت می‌کند، نه هویت سازنده را؛ این نسخه امضای دیجیتال ندارد. فقط از همین صفحه رسمی دانلود کنید.
- بررسی سایت فقط صفحه‌های HTML را می‌خواند و جاوااسکریپت را اجرا نمی‌کند.
- داده سرچ کنسول فقط با فایل CSV وارد می‌شود؛ اتصال مستقیم به حساب گوگل وجود ندارد.

**English summary.** First installable SEO OS release: a personal, Persian-first, self-hosted SEO workspace with no external services. Includes the guided workflow, keyword research and clustering, pages with an on-page checklist, an own-site page check, content briefs and calendar, tasks, internal link suggestions, Search Console CSV import with opportunities, a printable project report, browser installer, full backup/restore and updates with rollback. Requires PHP 8.4.1+ (extensions above), MariaDB 10.11+ or MySQL 8+, cron; point the web root at `public/` and open `/install`. SHA-256 sums prove integrity only; the release is not signed.
